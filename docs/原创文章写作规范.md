# 原创文章写作规范（v1.0）

> 适用范围：`js/data.js` 与 `js/articles-ext.js` 中全部原创英文文章（含 100 篇存量与后续新增）。
> 核心要求：**主题与风格严格对标对应主题的知名期刊/杂志；事件真实可靠；结构、语法与刊物惯例一致；可读性分级达标。**
> 本规范同时是新增文章的验收标准与存量文章改写的对照基线。

---

## 1. 主题 × 对标期刊对照表

每篇文章动笔前先确定「主题 → 对标刊物」，写作时以该刊的栏目文章为风格母版（可各选 1-2 篇近期文章精读后再写）：

| 项目主题 | 对标刊物 | 风格要点 |
|---|---|---|
| 励志成长 | The Atlantic（人物随笔）· Nautilus（人本科学随笔） | 第一/第三人称叙事交织；以具体人物困境开场；克制抒情，拒绝鸡汤口号 |
| 旅游文化 | National Geographic Traveler · BBC Travel | 场景式导语（place-based lede）：一个时刻、一个地点、一个感官细节；地方知识准确（地名/史实/习俗需核实） |
| 财经商业 | The Economist（Business & Finance 栏）· FT | 冷静克制、数据驱动、无作者署名的社论腔；段落短（2-4 句）；观点藏在事实排列中；善用反讽式收尾 |
| 科技生活 | Wired · MIT Technology Review | 解释性报道：新技术 → 谁在用 → 为什么现在 → 有什么争议；术语首次出现必须解释 |
| 健康生活 | New Scientist · Harvard Health Letter | 证据分级表述（study suggests / evidence shows / is associated with）；区分相关与因果；不做医疗建议 |
| 文化阅读 | The New Yorker（文化评论）· Aeon | 漫步式 essay：由一个具体文本/现象切入，层层展开思辨；允许更长的复合句 |
| 港航 / 港机 | gCaptain · Splash247 · The Loadstar | 行业操作视角：术语精确（berth / gangway / lashing）、数据带单位与年份、引用从业人员或机构 |
| 物流贸易 | JOC · The Economist（Trade 栏） | 政策—成本—链条三段式分析；引用机构数据（Drewry / Clarksons / 海关总署） |

**对标原则**：模仿的是「结构、语气、句式节奏、数据呈现方式」，**不模仿**受版权保护的具体表达——文字必须全部原创。

## 2. 结构要求（新闻体/刊物体通用骨架）

1. **Lede 导语**（35–60 词）：钩子式开场——一个场景、一个数字、一个反差。禁止 "In today's fast-paced world" / "With the development of society" 类空泛开头。
2. **Nut graf 核心段**（第 2–3 段）：一句话点明「这篇文章讲什么、为什么现在值得读」。
3. **主体**：沙漏结构——由具体到一般再回到具体；**每段只讲一个 idea**，段落 3–6 句；段间用逻辑过渡（contrast / causation / sequence），不用 "Moreover, ..., Moreover, ..."。
4. **Kicker 结尾**：三种合法收尾——回扣导语场景、前瞻一句趋势、或一条有力引语。禁止 "In conclusion" 式总结。

## 3. 语法与文体硬性规则

- **时态基准**：叙事用过去时；普遍事实用现在时；引语一律 `said`（不用 `stated / mentioned` 装饰），间接引语做时态回移（backshift）。
- **语态**：主动语态为主，被动 ≤ 15%（且仅用于施动者不明或不重要时）。
- **引语**：占比 10–25%（难度高级文章可至 30%）；每条引语必须有 attribution（`said Captain Li, a port pilot with 12 years of experience`）；不用无来源的 "experts say"。
- **句长**：长短板交错；连续三句同为长句即需拆分。
- **术语一致性**：同一概念全文只用一个词（首现加中文注释在术语表，不在正文）。
- **数字规范**：10 以下拼写、以上用阿拉伯；带单位与年份（`1.2m TEU in 2024`）；大数字给参照物（`roughly the annual throughput of Qingdao`）。
- **AI 味清除清单**（出现即返工）：
  - 空泛排比与三连形容词堆叠（`vibrant, dynamic and bustling`）
  - "delve into" / "plays a vital role" / "it is worth noting that"
  - 每段结尾机械总结句
  - 与主题无关的万能句（"English learning is important..."）

## 4. 事实可靠性（事件真实可靠）

1. **真实性底线**：涉及的事件、机构、政策、公司必须真实存在；**不得虚构具体人名 + 职务组合**（用真实公开人物，或改为匿名从业者 `a veteran pilot`）。
2. **数据溯源**：吞吐量、运价、政策日期等须来自公开可查来源（港务局年报、公司公告、政府统计、IMO/ILO/UNCTAD 报告），并在文章 `meta.src` 中登记来源线索（数组，每项 `{ d: 数据点, from: 来源 }`）。
3. **时效**：优先使用 24 个月内的数据；更旧的数据须标注年份并确认未被更新值取代。
4. **不确定即改写**：无法核实的数据改写为趋势性表述（`has grown steadily since the pandemic`）或删除；**禁止编造精确数字**。
5. **地理/常识核查**：地名、距离、气候、货币单位逐项核对。

## 5. 可读性分级指标（与文章难度档对应）

| 指标 | 低级 | 中级 | 高级 |
|---|---|---|---|
| Flesch Reading Ease | ≥ 70 | 60–70 | 50–60 |
| 平均句长（词） | ≤ 14 | 15–18 | 19–23 |
| 段落句数 | 3–4 | 3–5 | 4–6 |
| 全文词数 | 280–380 | 380–480 | 480–620 |
| 学术/专业词占比 | ≤ 6% | ≤ 9% | ≤ 12% |
| 教学目标词（术语表） | 8–12 | 12–18 | 18–26 |

可用零依赖脚本自测（后续可挂入 `tools/validate.js`）：
`node -e "…"`（Flesch = 206.835 − 1.015×ASL − 84.6×ASW，按音节数近似：元音组计数）。

## 6. 写作流程（每篇必走）

1. 定主题与对标刊物 → 精读该刊 1–2 篇近期同题文章（只学结构，不借表达）
2. 列事实清单：每个数据/事件/人名标注来源
3. 写提纲：lede → nut graf → 3–6 个主体段（各配事实或引语）→ kicker
4. 初稿 → 对照第 3 节清单逐条自查 → 读出声改节奏
5. 算可读性指标 → 调整句长与词级
6. 提取术语表入词典（`DICT`），跑 `node tools/validate.js`

## 7. 存量文章处置建议

100 篇存量文章按本规范分批复核改写（优先级：港航/港机/物流 > 财经 > 其他，因其事实密度最高）；每改完一批跑 `validate.js` 并在 `CHANGELOG.md` 登记。改写时保持词数与难度档不变，只提升结构、事实与文体合规性。
