# EverWord · 每日英语学习平台设计方案

> 版本 v1.0 · 2026-10-19 · 交付物：本设计方案 + 可运行纯前端原型（本仓库）
>
> **一句话定位**：以认知科学为底座的每日英语学习平台——每天 20 分钟，完成「学单词 → 读文章 → 做测验」的科学闭环。

---

## 一、产品概述

### 1.1 产品定位

EverWord 是一款面向中国英语学习者的**每日学习平台**。核心主张：不堆砌功能，只做好"每天值得完成的 20 分钟"。

- 以**间隔重复（Spaced Repetition, SM-2 算法）**调度单词记忆；
- 以**分级沉浸阅读**（悬浮释义 + 音频）在真实语境中巩固；
- 以**每日测验**驱动主动回忆（测试效应）；
- 三者共用一套生词数据，形成「输入 — 理解 — 提取」完整闭环，生词与错题自动回流次日复习队列。

### 1.2 目标用户

| 用户群 | 备考目标 | 日均可投入 | 核心诉求 |
|---|---|---|---|
| 高校学生 | CET-4 / CET-6 | 20–40 分钟 | 高频词 + 真题化练习 |
| 雅思备考者 | IELTS 6.0–7.0 | 30–60 分钟 | 学术词汇 + 阅读量 |
| 职场进阶者 | 无明确考试 | 10–20 分钟 | 阅读能力 + 保持语感 |

### 1.3 核心功能清单（四大模块）

| 模块 | 一句话说明 | 科学依据 |
|---|---|---|
| 每日单词推送 | SM-2 调度的新词学习与到期复习 | 间隔重复 / 艾宾浩斯遗忘曲线 |
| 每日文章推送 | 低/中/高分级文章，悬浮释义 + 音频，多主题 | 可理解输入 i+1 |
| 每日测验 | 10 题混合测验 + 错题针对性重练 | 测试效应（主动回忆） |
| 题库 | 四级/六级/雅思分类题库 + 答案与解析 | 提取练习 |

### 1.4 每日学习闭环

```
学（10 min 单词队列） → 读（7 min 分级文章） → 测（3–5 min 每日测验）
        ↑                                              ↓
        └──── 生词本 / 错题池自动回流次日队列（数据闭环）────┘
```

## 二、功能模块设计

### 2.1 每日单词推送（记忆曲线调度）

**学习价值**：把"背了忘、忘了背"的失控感，变成"系统知道你什么时候该复习"的确定感。

**每日队列构成**

- 新词：8 个/日（按词库顺序推进：CET-4 → CET-6 → IELTS 渐进）；
- 复习：当日到期卡片（`due ≤ 今日`），优先于新词展示。

**推送内容**：单词、音标（IPA）、词性 + 中文释义、英文例句 + 中文翻译、发音音频、级别标签。

**交互流程**

1. 进入单词页 → 顶部显示「新词 8 · 待复习 N · 已掌握 M」；
2. 卡片正面：单词（大号衬线）+ 音标 + 发音按钮；
3. 点击卡片或按空格 → 3D 翻转 → 背面：释义 + 例句（可播放例句语音）；
4. 四档自评：**忘记 / 模糊 / 良好 / 秒认**，每个按钮实时预览"下次复习间隔"；
5. 完成后进入报告页：今日学习统计 + 明日待复习数。

**调度算法（SM-2）**

- 初始间隔：`I(1) = 1 天`，`I(2) = 6 天`，此后 `I(n) = I(n-1) × EF`（向上取整）；
- 自评映射：忘记 q=2 / 模糊 q=3 / 良好 q=4 / 秒认 q=5；
- q < 3：卡片重置为新卡（明日重现），**当日会话内自动重排队列再测**；
- q < 4 当日重复出现（单卡重复上限 2 次，防止挫败感——工程化裁剪）。

示例轨迹（EF=2.5 的词）：**1 天 → 6 天 → 15 天 → 37 天 → 93 天 → …**

### 2.2 每日文章推送（分级沉浸阅读）

**学习价值**：在 i+1 难度的语境中再次遇见当天学过的词，完成记忆的第一次真实提取。

**难度分级**

| 难度 | 词汇量要求 | 文章长度 | 对应人群 | 阅读方式 |
|---|---|---|---|---|
| 低 | ≤ 2,000 词 | 200–300 词 | 四级预备 / 基础巩固 | 精读 + 跟读 |
| 中 | 2,000–4,500 词 | 400–600 词 | 四级 / 六级备考 | 精读 + 取词 |
| 高 | 4,500–8,000 词 | 600–900 词 | 雅思 6.0–7.0 | 泛读 + 学术词汇 |

**主题矩阵**（以积极向上为主，财经/时政类保持客观中立）

| 主题 | 调性 | 频率建议 | 内容来源 |
|---|---|---|---|
| 名人演讲 | 激励正向 | 每周 1 篇 | 公有领域演讲文本 |
| 励志成长 | 温暖治愈 | 高频 | 原创 |
| 旅游文化 | 轻松开阔 | 每周 2 篇 | 原创 / 授权 |
| 科技前沿 | 中性客观 | 每周 1–2 篇 | 原创 / CC 协议语料 |
| 财经商业 | 客观中立 | 每周 1 篇 | 原创 |
| 教育心理 | 实用理性 | 每周 1 篇 | 原创 / 公有领域 |

**悬浮释义**：鼠标悬停文中任意带虚线下划线的单词 → 悬浮卡片显示音标、词性、释义，附两个操作：**发音** / **加入生词本**。移动端改为点按触发。

**音频**：MVP 采用 Web Speech API 合成（零成本、即点即播，支持全文/段落播放与 0.8×/1×/1.2× 语速）；生产阶段替换为真人录音（单词 + 例句）与段落音频。

**生词联动**：阅读中一键加入生词本 → 直接进入 SM-2 复习队列（次日到期）。

### 2.3 每日测验

**学习价值**：测试效应（Testing Effect）——主动提取比重复阅读的长期留存显著更高（Roediger & Karpicke, 2006）。

**出题策略（每日 10 题，当日种子固定）**

| 题型 | 数量 | 题源 |
|---|---|---|
| 词汇释义四选一 | 2 | 当日新词 |
| 语境填空四选一 | 2 | 当日新词例句改造 |
| 语境词汇 | 1 | 全库词 |
| 语法 | 2 | 高频考点（时态 / 虚拟语气 / 倒装） |
| 阅读理解 | 2 | 当日推荐文章 |

**反馈机制**：每题即时判定 + 解析；结束后得分环、逐题回顾、**错题一键重练**；错题记录进入次日复习池。

**自适应性（V1.2）**：按正确率动态调整词汇题难度（连续答对 → 提高 IELTS 词汇占比）。

### 2.4 题库（四六级 + 雅思 + 答案）

**组织结构**：考试（CET-4 / CET-6 / IELTS）→ 题型（词汇 / 语法 / 阅读）→ 题目（题干、选项、答案、解析、标签）。

- **浏览模式**：逐题"显示答案"自测；
- **练习模式**：整卷进入测验引擎，即时判分。

**版权合规（重要）**

1. 四六级 / 雅思真题原文受版权保护，**直接复制存在侵权风险**；
2. 合规路径：① 自编高质量模拟题（本原型采用）；② 与出版方 / 考试机构谈内容授权；③ 使用公有领域语料（早期演讲、Project Gutenberg 公版书）改编；
3. 题库存量建议：MVP 每考试 6 题演示结构 → V1 每考试 300+ 题。

## 三、科学原理

### 3.1 艾宾浩斯遗忘曲线

记忆留存 R 随时间 t 近似指数衰减：**R ≈ e^(−t/S)**（S 为记忆强度）。无复习时，新词 24 小时后留存仅约 1/3；在遗忘临界点之前插入复习，留存曲线被"抬升复位"，且每次复习使 S 增大、衰减变慢——这是间隔重复的数学基础。

### 3.2 SM-2 间隔重复算法（本平台核心调度）

> 来源：SuperMemo 官方算法文档（Wozniak, 1987）。

每张卡片维护三个状态：**EF**（难度因子，初始 2.5）、**reps**（连续答对次数）、**interval**（当前间隔天数）。

**间隔规则**

- `I(1) = 1` 天，`I(2) = 6` 天；
- `I(n) = I(n-1) × EF`（向上取整）。

**EF 更新公式**（q 为 0–5 的回忆质量评分）：

```
EF' = EF + ( 0.1 − (5−q) × (0.08 + (5−q) × 0.02) )，且 EF' 下限 1.3
```

**按钮 → q 映射与行为**

| 按钮 | q | EF 变化 | 间隔行为 |
|---|---|---|---|
| 忘记 | 2 | 不变（算法规范如此，工程上可选 −0.2 惩罚） | 重置为新卡：明日重现，当日会话内重排再测 |
| 模糊 | 3 | −0.14 | 正常推进；当日再测一次 |
| 良好 | 4 | 0 | 正常推进 |
| 秒认 | 5 | +0.10 | 正常推进 |

示例轨迹（EF=2.5）：1 → 6 → 15 → 37 → 93 天。

**升级路径**：V1.2 迁移到 **FSRS**（开源 open-spaced-repetition 项目，基于三组分记忆模型 DSR，按用户个人遗忘速度拟合参数，精度优于固定参数的 SM-2）。

### 3.3 测试效应（主动回忆）

Roediger & Karpicke（2006）经典实验：学习后进行**提取测试**的组，一周后记忆留存显著高于重复阅读组。本平台的每日测验、卡片自评、错题重练，均为"提取练习"的具体化。

### 3.4 可理解输入（i+1）与沉浸阅读

Krashen 输入假说：当输入略高于当前水平（生词率 2–10%）时习得效率最高。三档分级 + 悬浮释义即时消歧，把"跳查词典打断心流"的认知负荷降到最低。

### 3.5 每日剂量与认知负荷

- 新词 8 个/日 + 到期复习 ≈ 每天 10–25 张卡，20 分钟内完成；
- 依据：新词引入速率超过 10–15 个/日时，复习负担将指数增长（SM-2 原作者日均 41 分钟即完成约 30 项复习）。

## 四、信息架构与关键交互

### 4.1 站点地图

```
首页（今日仪表盘）
├── 单词 · 每日单词（SM-2 队列）
├── 阅读 · 每日文章（分级 / 主题 / 悬浮释义 / 音频）
├── 测验 · 每日测验（10 题 + 错题重练）
└── 题库 · 四六级 / 雅思（浏览 + 整卷练习）
    └── 生词本（隐藏层：跨模块数据汇合点，融入复习队列）
```

### 4.2 页面结构

| 页面 | 核心区块 |
|---|---|
| 首页 | 每日任务三卡片（实时进度）· 学习统计 · 今日推荐文章 · 记忆曲线示意 |
| 单词 | 队列统计条 · 3D 翻转卡片 · 四档评分 · 完成报告 |
| 阅读 | 难度切换 · 文章元信息 · TTS 工具栏 · 可取词正文 · 完成标记 |
| 测验 | 题目卡（题干 / 选项 / 解析）· 进度条 · 结果页（得分环 / 回顾 / 错题重练） |
| 题库 | 考试 Tab · 题目列表（显示答案）· 整卷练习入口 |

### 4.3 关键交互流程（每日学习流）

1. 首页一键「开始今日学习」→ 单词页完成队列（翻卡 / 评分 / 语音）；
2. 结束页引导 → 阅读页当日推荐文章（遇生词 → 悬浮 → 加入生词本）；
3. 文末引导 → 测验页 10 题 → 结果页错题重练；
4. 全部完成 → 首页任务卡点亮，连续学习天数 +1。

**生词数据流**：阅读取词 / 测验错题 → 生词本 → 次日 SM-2 队列 → 掌握后自动归档。

## 五、技术选型

### 5.1 分阶段架构

| 层 | MVP（本原型） | V1.1 生产版 |
|---|---|---|
| 前端 | 原生 HTML / CSS / JS（零依赖） | Vue 3 + Vite + TypeScript |
| 视觉 | 手写设计系统（CSS 变量） | 同设计系统 → Tailwind tokens |
| 音频 | Web Speech API 合成 | 真人录音 + 对象存储 CDN |
| 数据 | localStorage | **MySQL 8（按需采用，已确认）** + Redis 缓存 |
| 后端 | 无 | Node.js（NestJS）REST API |
| 调度 | 客户端 SM-2 | 服务端 SM-2 / FSRS + 每日内容定时任务（cron） |
| 部署 | 静态托管 | Nginx + PM2 / Docker Compose |

### 5.2 数据库设计（MySQL 8，按需采用）

核心表草案：

```sql
CREATE TABLE word (
  id           INT PRIMARY KEY AUTO_INCREMENT,
  headword     VARCHAR(64)  NOT NULL,
  ipa          VARCHAR(96),
  pos          VARCHAR(24),
  definition   VARCHAR(255) NOT NULL,
  example      TEXT,
  example_zh   VARCHAR(512),
  level        ENUM('CET-4','CET-6','IELTS') NOT NULL,
  freq_rank    INT,
  UNIQUE KEY uk_headword (headword)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE review_card (            -- SM-2 卡片状态
  id         BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id    BIGINT  NOT NULL,
  word_id    INT     NOT NULL,
  ef         DECIMAL(3,2) NOT NULL DEFAULT 2.50,
  reps       SMALLINT NOT NULL DEFAULT 0,
  ivl_days   SMALLINT NOT NULL DEFAULT 0,
  lapses     SMALLINT NOT NULL DEFAULT 0,
  due_date   DATE     NOT NULL,
  UNIQUE KEY uk_user_word (user_id, word_id),
  KEY idx_user_due (user_id, due_date)   -- 每日队列：过滤下推到 SQL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE quiz_log (
  id           BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id      BIGINT NOT NULL,
  question_id  INT    NOT NULL,
  is_correct   TINYINT(1) NOT NULL,
  created_at   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_user_time (user_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 另需：user / article / article_gloss（文章释义词表）
--        question（题库）/ user_vocab（生词本，含来源：阅读/测验）
```

要点：每日队列查询通过 `idx_user_due` 索引将过滤下推到 SQL 层（`WHERE user_id=? AND due_date<=CURDATE()`），不在应用层全表捞取后过滤；Redis 缓存当日内容与连续天数计数。

### 5.3 前端关键交互实现

- 翻转卡片：CSS 3D transform（`preserve-3d` + `backface-visibility`）；
- 悬浮取词：正文分词 → 词典命中词加虚线标记 → 单例 Tooltip（暗色墨水卡片，含发音与加生词操作）；
- TTS：`speechSynthesis` 段落队列播放，`onend` 串联；
- 动效：仅 `transform / opacity` + `IntersectionObserver` 入场动画（GPU 安全）。

## 八、原型说明（随本方案交付）

- **文件结构**：`index / words / reading / quiz / bank` 5 个页面 + `js/`（data / srs / tts / quiz / app）+ `css/styles.css`；
- **运行方式**：直接用浏览器打开 `index.html`（无需构建、无需服务器）；
- **已实现**：SM-2 调度（localStorage 持久化）、36 个分级单词、3 篇分级文章（悬浮释义 + TTS）、每日测验（当日种子自动出题 + 错题重练）、题库 18 题及解析；
- **已知限制**：音频为浏览器合成语音（质量因设备而异）；数据存于本地浏览器；题目为原创示例题，真题接入需按 2.4 节版权合规路径处理。
